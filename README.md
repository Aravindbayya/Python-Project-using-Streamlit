# Electricity Bill Generator
## Problem Statement

In many **households** and **commercial establishments**, electricity bills are calculated based on the number of units consumed during a billing period. Calculating bills manually can be **time-consuming** and may lead to errors in unit charges, surcharges, and total amounts.

## Project Overview

The **Electricity Bill Generator** is a Python-based mini project developed using **Object-Oriented Programming (OOP)** and **Streamlit**. It calculates electricity charges based on the number of units consumed by a customer.

The application accepts customer details, calculates the energy charges according to predefined unit-based slabs, applies an additional surcharge when applicable, and displays the final electricity bill.

This project is designed to demonstrate Python concepts such as classes, objects, conditional statements, functions, and user input handling.

## Objectives

- To develop an electricity bill calculation application using Python.
- To understand and implement classes and objects.
- To use conditional statements for calculating electricity charges.
- To create reusable methods for bill calculation.
- To build a simple and interactive user interface using Streamlit.
- To display a detailed electricity bill based on customer information.

## Features

- Enter customer name and consumer number.
- Input the total electricity units consumed.
- Calculate electricity charges using predefined tariff slabs.
- Apply a 5% surcharge when consumption exceeds 300 units.
- Display the energy charge, surcharge, and total bill.
- Provide an interactive web interface using Streamlit.

## Technologies Used

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **Concepts:** Classes, objects, functions, conditional statements, and encapsulation basics
